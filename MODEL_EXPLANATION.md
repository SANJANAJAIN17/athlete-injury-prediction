## Model Explanation

### Logistic Regression
Used to estimate the probability of a serious injury based on workload and physical attributes. Coefficients were analyzed to understand how each variable influences injury risk.

### Decision Tree
Developed to create an interpretable, rule-based model. The pruned tree highlights key decision points such as games played and age.

### KNN
Applied to capture non-linear patterns in the data after standardizing features. Cross-validation was used to select the optimal value of k.

### Why Multiple Models?
Using multiple models allows comparison between interpretability and predictive performance, ensuring reliable and actionable insights.
